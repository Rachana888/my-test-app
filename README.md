# 🌸 ZenFlow — Yoga Essentials & Accessories

A React app showcasing curated yoga essentials and healing accessories for peace and mindful living.

## Features

- **Hero section** with peaceful branding and call-to-action
- **6 product categories**: Yoga Mats, Meditation Cushions, Aromatherapy, Sound Healing, Herbal Teas, Malas & Crystals
- **8 featured products** with ratings, reviews, and tags
- Calming sage-green and earth-tone color scheme
- Fully responsive design

## Getting Started

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Running Tests

```bash
npm test
```
